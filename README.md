# Course Overview – RTL Design & Design Verification
This repository documents my learning journey through a 15-session RTL Design and Design Verification course, progressing from fundamental digital design concepts to an integrated RTL/DV Final Project.

- Session 01 – ASIC Design Flow: Introduction to the ASIC development process, including specification, architecture, RTL design, pre-silicon verification, synthesis, physical design, and tape-out. 
- Session 02 – Linux, Vim & EDA: Familiarization with the Linux development environment, command-line operations, file management, Vim, and basic EDA workflows. 
- Session 03 – Verilog Fundamentals I: Study of Verilog syntax, data types, number representation, assignments, operators, and synthesizable versus non-synthesizable code. 
- Session 04 – Verilog Modules: Understanding module structure, ports, interfaces, module instantiation, and hierarchical RTL organization. 
- Session 05 – Combinational Logic: Practice with always blocks, blocking assignments, multiplexers, encoders, decoders, and proper combinational coding techniques. 
- Session 06 – Sequential Logic: Introduction to latches, flip-flops, clocked logic, asynchronous reset, and non-blocking assignments. 
- Session 07 – Sequential Logic Practice: Practical study of multi-bit flip-flops and simulation race conditions, with emphasis on correct testbench timing. 
- Session 08 – Parameter & FSM: Introduction to parameters, functions, generate constructs, and Finite State Machine design for reusable and structured RTL. 
- Session 09 – Verilog for Verification: Use of initial blocks, loops, delays, and tasks to create reusable verification stimulus. 
- Session 10 – Testbench & Verification Plan: Study of testbench architecture, stimulus, checkers, verification flow, testcase planning, and VPLAN development. 
- Session 11 – Verification Practice: Hands-on verification exercises combining stimulus generation, functional checking, and debugging techniques. 
- Session 12 – Register Module: Study of address mapping, byte/word organization, register behavior, and software–hardware interfaces. 
- Session 13 – Register Design Practice: Requirement analysis, waveform planning, logic-diagram development, RTL implementation, and review of register designs. 
- Session 14 – Register Verification & APB: Verification of register behavior and introduction to APB protocol timing, read/write transactions, and protocol compliance. 
- Session 15 – Code Coverage & Final Project: Introduction to statement, branch, expression, condition, and toggle coverage, followed by an integrated RTL/DV Final Project.
