## SESSION 02 – LINUX, VIM, EDA

This session introduced the fundamental development environment commonly used in RTL Design and Design Verification. I practiced navigating and managing files in Linux, editing source files with Vim, organizing a basic RTL project structure, and preparing the required file lists and simulation environment. The session also provided my first hands-on experience with the workflow of managing RTL source code, testbench files, simulation scripts, and EDA tools from the command line.

### My Exercises

- Linux directory and file management practice
- Basic Vim editing and command practice
- RTL project directory setup
- RTL and testbench file-list configuration
- Basic simulation environment setup
- Compile and simulation workflow practice

### What I Practiced

- Navigating Linux directories using `pwd`, `cd`, `ls`, and `tree`
- Creating and managing files and directories with `mkdir`, `touch`, `cp`, `mv`, and `rm`
- Understanding absolute and relative paths
- Editing source files using Vim insert and command modes
- Using basic Vim operations such as save, quit, undo, delete, search, and line numbering
- Organizing RTL, testbench, and simulation files into a structured project hierarchy
- Creating file lists for RTL and testbench compilation
- Running a basic compile and simulation flow through the command-line environment
- Developing familiarity with an EDA-oriented Linux workflow
