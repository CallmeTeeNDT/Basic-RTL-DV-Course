## SESSION 03 – VERILOG FUNDAMENTALS: DATA TYPES & OPERATORS

This session introduced the fundamental syntax and concepts of Verilog HDL, including number representation, data types, assignments, and commonly used operators. The homework focused on applying these concepts through simulation by implementing and evaluating different Verilog operator examples, then comparing the obtained results with the expected behavior presented during the session.

### My Exercises

- Verilog number representation practice
- Arithmetic operator practice
- Relational and equality operator practice
- Logical operator practice
- Bitwise operator practice
- Reduction operator practice
- Shift operator practice
- Conditional operator practice
- Operator behavior verification using a testbench

### What I Practiced

- Declaring and assigning Verilog variables and values
- Working with binary, decimal, octal, and hexadecimal representations
